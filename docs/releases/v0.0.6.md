Seihai 0.0.6: the Graal client (mae for 1.x/2.x, ato for 3.x and later, g3d for Graal3D) and `seihai-core`, the library the Seihai servers build on. This tag is the one the server repos will move to next.

## New since 0.0.5

**For the servers and tools**
- **`seihai-draw`** (#350): a shared RGBA tile and gani drawing crate, used by seihai-servertools' level and gani editors. This is the first tag that has it, so servertools can stop pinning a commit.

**Client**
- Game connections turn Nagle off, so small packets such as movement go out at once (#360).
- Version profiles: 1.39 knockback and respawn (#347), the 1.39 death row in the profile chain (#351), and each profile's main-window size (#349).
- The launcher README now says ato draws (flat 2D) (#356).

**Quality**
- Every pull request now builds and tests on Linux, macOS and Windows (#354). Two timing races that this CI found are fixed (#358).
- Ghidra tooling and Ghidra-derived names are gone from the client and its docs (#348, #355). Recovered-tool notes now point to Graal_analysis and seihai-servertools (#339–#346).
- Releases are drafts that the owner publishes (#359).

**Planning docs**
- The Graal3D hosting and world-content milestones (#352), trainer threats and server-side defences (#337), and the contributor binding rules (#336).

## Download

Each archive holds `seihai`, `seihai-mae`, `seihai-ato` and `seihai-g3d`. They come for Linux x86_64 and Windows x86_64. On Linux, sound needs ALSA. Archives for macOS Intel (x86_64) and Apple Silicon (aarch64) are added to this release when GitHub's macOS build machines have room; if they are not here, build from source with `cargo build --release`. On macOS, the first start may need right-click → Open, because the build is not signed.

Start with `seihai` (the launcher). It picks mae or ato for the client version you choose.
