Seihai 0.0.7: the Graal client (mae for 1.x/2.x, ato for 3.x to 5.x, issho for 6.x, g3d for Graal3D) and `seihai-core`, the library the Seihai servers build on. The NPC-server moves to this tag next, for `playerlogin` and `playerlogout`.

## New since 0.0.6

**For the servers and tools**
- **`playerlogin` and `playerlogout`** are script events from the 2.1 era (#416), for server-side NPCs with no level, such as a GServer-v2 world's Control-NPC. They are a Seihai extension: the original Graal clients have no such events, and no client fires them.
- **GS1 to GS2 compiler** (#414, #422): array elements `a[i]` and `a[i, j]` (read, write, `+=` and the other compound forms, `++`, `--`), `x in arr`, and `x in {a, b, c}`. `documentation/gs1-to-gs2.md` lists what is lowered, what each form is checked against, and what is still refused (#371 tracks the rest).

**Client (Ato, 3.x to 5.x)**
- Draws the level's NPCs and the server's NPCs from their images, and other players' nicknames (#417).
- Plays a level file offline with `--level`, following links (#418).
- Walks gmaps offline and draws the neighbouring levels (#419), and online enters the server's gmap and sends each crossing as the client does (#420).

**Docs**
- The Mae / Ato / Issho cut line, and stale routing rows fixed (#415). The release table records the npcserver v0.1.1 and gserver v0.1.0 releases (#413).

## Known not to work yet

- Ato draws in 2D with no GANI art; its 3D (Torque) path is held until a capture exists. Board changes from the server and the neighbouring levels' NPCs on an online gmap are not in this release.
- `seihai-issho` does not draw.
- The GS1 to GS2 compiler accepts a subset; anything else is a clear compile error. Nothing it produces has been run on an original client.

## Download

Each archive holds `seihai`, `seihai-mae`, `seihai-ato`, `seihai-issho` and `seihai-g3d`. They come for Linux x86_64 and Windows x86_64. On Linux, sound needs ALSA. Archives for macOS Intel (x86_64) and Apple Silicon (aarch64) are added to this release when GitHub's macOS build machines have room; if they are not here, build from source with `cargo build --release`. On macOS, the first start may need right-click → Open, because the build is not signed.

Start with `seihai` (the launcher). It picks mae, ato, issho or g3d for the client version you choose. Keep the five programs in one folder.
